# Editorial Modernist

A mod that draws the Claude desktop app in the Editorial Modernist design system. It follows the app's light or dark setting: light lilac and royal violet by day, deep midnight and luminous orchid by night.

It also sets conversation type: serif headings, sans body text, mono tool rows, and rounded message bubbles with a hairline border. The colors and type are in `hooks/look.ts`.

## Install

At the prompt of a terminal session:

```
/plugin install editorial-modernist --marketplace inevitabledoubt/editorial-modernist
```

From a shell:

```
claude plugin install editorial-modernist --marketplace inevitabledoubt/editorial-modernist
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `inevitabledoubt/editorial-modernist`, then Add plugin.

## Good to know

- Mods can only choose generic font families, so the fonts are your system's serif, sans and mono.
- In dark mode the white switch knob is 2.65:1 on the orchid accent, under the 3:1 guideline.
